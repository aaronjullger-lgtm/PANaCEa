# Landing asset provenance

Created September 23, 2026 for the owner's PANaCEa reference overhaul.

## Decorative learning sculpture

- Shipping assets: `learning-sculpture.webp` (1600 × 667, 105,632 bytes) and `learning-sculpture-small.webp` (800 × 333, 37,776 bytes).
- Origin: OpenAI image generation tool in the authorized design session. The owner's supplied landing reference was provided as a material/composition style reference. It is not bundled in the repository.
- Generation request: wide transparent still life, brain on navy pedestal with frosted-glass study tiles, no tablet or text. The returned 1920 × 800 PNG was converted to two alpha-preserving WebP delivery sizes using Sharp.
- Placement: decorative hero foreground, empty alt text, no interaction, underneath the readable HTML study preview. No clinical teaching or diagnostic use.
- Rights context: generated for this project; no downloaded stock image or third-party attribution claim. The raw image and supplied reference remain session inputs rather than shipping public assets.
- Validation: generated asset inspected visually; final browser composition remains unverified because the supported preview was blocked.

Exact generation prompt:

> Use case: stylized-concept. Asset type: decorative transparent cutout for the PANaCEa clinical learning website hero. Input image is a style reference only. Create a premium, photorealistic 3D still life matching the reference's cool silver-blue material world: a detailed pale porcelain-gray brain on a short brushed dark navy circular pedestal at the right, with three thin translucent frosted-glass medical study tiles extending low across the foreground to the left. Tiles have only subtle engraved nonverbal neural connections and a simple heartbeat line, absolutely no lettering. A fine silver fiber cable gracefully connects the tiles to the brain. Brain has one tiny soft ice-blue luminous point, no neon. Composition very wide landscape, brain occupies right third, tiles occupy lower left, all objects fully visible with generous clear margins. Low three-quarter camera view. Soft diffuse studio daylight, realistic glass refraction, understated soft grounding shadow. Isolated on genuinely TRANSPARENT background with alpha, no floor plane, no solid background. No tablet, no laptop, no UI, no words, no logos, no labels, no watermark. This is decorative marketing artwork, not an anatomical teaching diagram.

## Font

- Shipping font: `public/fonts/Manrope-Latin.woff`, variable weight 200–800, 27,800 bytes.
- Source: [Google Fonts Manrope directory](https://github.com/google/fonts/tree/main/ofl/manrope), downloaded `Manrope[wght].ttf` during this session.
- Conversion: FontTools subset to U+0020–00FF and U+2000–206F, WOFF delivery. Scoped CSS family name `Manrope Landing`; system/application fallbacks remain available.
- License: SIL Open Font License 1.1. Unmodified license and copyright notice ship at `public/fonts/Manrope-OFL.txt`.
