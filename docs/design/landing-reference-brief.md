# Public landing reference overhaul

Scope: unauthenticated landing route and its authentication presentation. Mode: Persuade. The signed-in application and earlier usability fixes remain separate surfaces.

## Direction contract

**THESIS:** Study with purpose; remember with confidence. Make behavioral, concept-level spaced repetition tangible through a readable next-concept preview.

**OWN-WORLD:** Silver-white and ice-blue fields alternate with deep navy sections. Fine dividers, restrained rounded corners, blue clinical accents, and a sculptural brain/glass still life follow the owner's supplied reference.

**STORY:** Recognize the study problem, see a personal plan, understand the five-stage behavioral memory loop and fresh-question retrieval, explore practice modes, then create an account.

**FIRST VIEWPORT:** Large four-line headline and sign-up action on the left; a navy tablet-like HTML study preview on the right; transparent generated sculpture overlaps only decorative space below it. On phones the same content stacks without perspective or hidden controls.

**FORM:** Owner-pinned full-page reference. No random concept selection; the supplied reference settles composition and material direction. Impeccable launcher was unavailable earlier in this session, so context and reference checks are manual; no seed or automated fidelity score is claimed. The only authored motion is a short, already-visible product entrance, removed for reduced motion. The working interaction is explicit selection of practice modes.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Content decisions

Keep existing Clerk entry points and available study-mode descriptions. Substitute demonstrated practice capabilities for unverifiable testimonial cards and improvement percentages. Label the tablet's sample data. CTA says “Build my study plan” because it opens account creation, not a guaranteed free assessment or payment offer. Existing section anchors remain supported. No new production dependency, patient content, or database change.

Phone, tablet and desktop layout; visible focus; menu Escape/focus restoration; accessible tab selection; auth modal containment; reduced motion; optimized image with dimensions; tests, lint, typecheck and build evidence. Document blocked checks honestly.
