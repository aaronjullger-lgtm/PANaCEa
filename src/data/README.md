# Generated Case Content

This directory contains JSON files with generated medical cases for PANaCEa's Mini Modes.

## Files

- **`labCases.json`**: 250 lab interpretation cases (Generated by `npm run generate:lab`)
- **`clinicalCases.json`**: 250 clinical presentation cases (Generated by `npm run generate:clinical`)

## Generating Content

To generate the case files, you need a Gemini API key:

```bash
# Set your API key
export GEMINI_API_KEY="your-api-key-here"

# Generate lab cases (creates labCases.json)
npm run generate:lab

# Generate clinical cases (creates clinicalCases.json)
npm run generate:clinical

# Test with small sample (2 cases each)
npm run generate:test
```

See `scripts/README_CONTENT_GENERATION.md` for detailed documentation.

## Usage Example

### Lab Cases

```typescript
import type { LabCase } from '@/src/types/content';
import labCases from '@/src/data/labCases.json';

// Type-safe access to lab cases
const cases: LabCase[] = labCases;

// Example: Get a random case
const randomCase = cases[Math.floor(Math.random() * cases.length)];

// Access lab values
console.log(randomCase.correctDiagnosis);
console.log(randomCase.labs.BMP); // Basic Metabolic Panel
console.log(randomCase.labs.CBC); // Complete Blood Count
console.log(randomCase.labs.LFT); // Liver Function Tests

// Check for abnormal values
const abnormalLabs = randomCase.labs.BMP.filter(lab => lab.flag !== 'N');
```

### Clinical Cases

```typescript
import type { ClinicalCase } from '@/src/types/content';
import clinicalCases from '@/src/data/clinicalCases.json';

// Type-safe access to clinical cases
const cases: ClinicalCase[] = clinicalCases;

// Example: Get a random case
const randomCase = cases[Math.floor(Math.random() * cases.length)];

// Access presentation clues by type
const buzzwords = randomCase.presentationClues
  .filter(clue => clue.type === 'buzzword')
  .map(clue => clue.description);

const physicalExamFindings = randomCase.presentationClues
  .filter(clue => clue.type === 'physical_exam')
  .map(clue => clue.description);

const historyElements = randomCase.presentationClues
  .filter(clue => clue.type === 'history')
  .map(clue => clue.description);
```

## Data Structure

### LabCase

```typescript
{
  id: string;              // Unique identifier
  correctDiagnosis: string; // The diagnosis
  clinicalVignette: string; // Patient presentation
  labs: {
    BMP: LabValue[];       // Basic Metabolic Panel
    CBC: LabValue[];       // Complete Blood Count
    LFT: LabValue[];       // Liver Function Tests
  }
}
```

### ClinicalCase

```typescript
{
  id: string;                      // Unique identifier
  correctDiagnosis: string;        // The diagnosis
  vignette: string;                // Detailed patient presentation
  presentationClues: Array<{
    type: 'buzzword' | 'physical_exam' | 'history';
    description: string;
  }>
}
```
