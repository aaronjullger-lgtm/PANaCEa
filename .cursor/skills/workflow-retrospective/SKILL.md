# Workflow retrospective

Capture what to do better next time. Store in `.cursor/memory/workflow-retrospectives.md`.

## When to use
- After a complex/multi-agent task, a loop, or a notable friction/insight.

## Instructions
1. Add a dated entry: task + workflow used; what went well; what went wrong/friction; root cause; lesson → where recorded; follow-up.
2. If the lesson is a recurring mistake, also update `known-failure-modes.md` / `do-not-repeat.md`.
3. If a pattern repeated ≥2×, propose (don't force) a new rule/skill via `suggesting-cursor-rules`/`suggesting-cursor-hooks`.
4. Keep it a few lines; no secrets/PII/logs.

## Stop conditions
- Stop after one concise entry is recorded.

## Verification evidence
- The retrospective entry + any linked memory updates.

## Do not claim success unless
- The entry is committed to the memory file.

## Recovery
- Too vague to be useful → tie it to a concrete cause and a concrete next action, or omit it.
